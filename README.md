# dictum-binder

A new product, documented under the **Dictum** build-ready documentation
standard (v1.2.0, vendored at [`dictum/`](dictum/)).

The doc set is not yet scaffolded. Product scope, traits, and the concern
partition are decided in the `doc-scaffold` intake; this file is regenerated
from the manifest once that exists.

See [`CLAUDE.md`](CLAUDE.md) for how the standard and its tooling are laid out
in this repo.
